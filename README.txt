EMPLOYEE MANAGEMENT SYSTEM - LOGIN READY

1. Open this project in IntelliJ IDEA.
2. Make sure MySQL Connector/J is added to the project.
3. In MySQL Workbench, run database_setup.sql.
4. Check src/database/DatabaseConnection.java and set the MySQL USER/PASSWORD to your own values.
5. Run src/Main.java (GUI.Main).
6. The application opens the Login screen first.
7. After a successful login, it opens the Dashboard automatically.
